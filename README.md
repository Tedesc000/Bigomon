# Como executar o projeto

### 1. Configuração do banco de dados
- Abra o DBeaver e estabeleça uma conexão com o MySQL.
- Execute o arquivo `build.sql` para criar o banco de dados com a estrutura e os dados iniciais do projeto.

### 2. Inicialização do servidor
- Abra o XAMPP e inicie os serviços **Apache** e **MySQL**.
- Certifique-se de que ambos estejam em execução.

### 3. Acesso ao jogo
- Abra seu navegador.
- Acesse `http://localhost/` e navegue até a pasta do projeto, caso necessário.

---

### Observações
- **Evoluções Pokémon:** O projeto apresenta uma limitação no tratamento de Pokémon que possuem múltiplas possibilidades de evolução.
